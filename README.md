# Digital_-feedback-_management-_system
DIGITAL FEEDBACK MANAGEMENT SYSTEM 

Project Overview

The Digital Feedback Management System is a web-based application designed to collect, manage, and analyze feedback digitally. It replaces traditional paper-based feedback methods and provides a faster, more efficient way to gather user opinions.

Problem Statement

Traditional feedback collection methods are time-consuming, difficult to manage, and prone to data loss. There is a need for a digital platform that enables easy feedback submission, secure storage, and efficient analysis of feedback data.

Project Objectives

- Develop a digital platform for collecting feedback.
- Store feedback securely in a database.
- Provide an easy-to-use interface for users and administrators.
- Generate reports from collected feedback.
- Improve the efficiency of feedback management.

Technologies Used 

Frontend
  HTML
  CSS
  JavaScript

Backend
   MySQL Database


Advantages
  Easy feedback collection
  Reduces paperwork
  Quick report generation
  Secure data storage
  Improves decision-making
